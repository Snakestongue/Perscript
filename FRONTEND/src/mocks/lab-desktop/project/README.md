# Robot project

A small WPILib command-based project for practice.

- Edit the Java files in `src/main/java/frc/robot/`.
- Run `./gradlew build` in the terminal to compile.
- Run `./gradlew deploy` to send the code to the (simulated) robot.

Your goal: make the elevator's height show up in the Elastic dashboard.
Open `subsystems/Elevator.java` and find the TODO.
